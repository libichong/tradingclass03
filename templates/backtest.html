    公开代理公式与数据定义

    r 为快照最新价形成的 1 分钟收盘收益；窗口不使用未来值。金额 = Price×Volume，未核验供应商单位。BSFlag 66/83/0 = 主动买/主动卖/未知；未知计入总额，不计入方向净额。新增委托只取 OrderKind=65，FunctionCode 66/83 为买/卖。大单按每笔成交额判断，不按原始母单合并。

    回测假设、指标定义与数据质量

      每期使用上一完整分钟及更早数据排序，下一分钟第一条有效快照最新价作为买价代理，持有 H 分钟后用对应分钟第一条有效快照价格平仓。每期全额开平仓；不跨午休，不交易最后不足完整区间的时段。缺失成交价格时拒绝回测，不按未来价格可用性剔除股票。

      G1 为最低因子组，最高组由分组数决定。相同值按证券代码排序；不同值不足分组数时整期不交易。基准为同一期全部有效证券等权组合，并扣除相同费用。累计相对收益 = 策略净值 / 基准净值 − 1。多空为 50% 高组 / 50% 低组、总敞口 1；低因子方向时对调，不含融券成本。

      令 c = (单边手续费 + 单边滑点) / 10000。多头每期净收益 = (1+毛收益)×(1−c)/(1+c)−1。多空净收益 = 0.5×(多头毛收益−空头毛收益)−c×[2+0.5×(两腿毛收益之和)]。收益按期复利；期频夏普 = 均值 / 样本标准差（无风险利率 0）；不足两期或零方差显示“无定义”。最大回撤 = max(1−净值/此前峰值)，包含初始净值 1。
